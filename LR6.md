# LR6 — Мониторинг пайплайна, Webhooks и Telegram-оповещения

**Дата:** ноябрь 2026 · **Проект:** [Neckrite/2DPlatformerLab](https://github.com/Neckrite/2DPlatformerLab) · **Файлы:** [main.yml](.github/workflows/main.yml)

## Цель

Настроить обратную связь от облачного сервера команде разработки:
после каждого прогона пайплайна Telegram-бот отправляет сообщение
с результатом (успех или упавшая задача).

## Шаг 1. Создание Telegram-бота

1. @BotFather → `/newbot` → имя и username
   (`neckrite_platformer_ci_bot`).
2. Скопирован токен доступа.
3. В чате с ботом нажат Start — бот не может писать первым.
4. chat_id получен запросом `getUpdates`.

## Шаг 2. Секреты репозитория

- `TELEGRAM_BOT_TOKEN` — токен бота;
- `TELEGRAM_CHAT_ID` — идентификатор чата.

Токен и chat_id не встречаются ни в main.yml, ни в файлах проекта:
при утечке бот компрометируется (единственное решение —
/revoke у @BotFather).

## Шаг 3. Задача notify в пайплайне

Задача `notify` включена в `needs` всех остальных задач
(`sanity_check`, `run_tests`, `build_game`, `build_docker_image`,
`deploy_to_pages`), а условие `if: always()` гарантирует запуск даже
при падении зависимостей. Статус каждой задачи читается выражением
`${{ needs.<имя_задачи>.result }}`; первый упавший этап определяет
текст сообщения. Отправка выполняется curl-запросом к
`https://api.telegram.org/bot<TOKEN>/sendMessage` с JSON
`{"chat_id": ..., "text": ...}`.

Гвард `github.repository == 'Neckrite/2DPlatformerLab'` не дает
уведомлениям зациклиться через резервный репозиторий.

## Шаг 4. Оба сценария

- **Успешный:** в Telegram приходит сообщение «Сборка завершена
  успешно» с именем автора коммита, ссылкой на игру
  (GitHub Pages) и ссылкой на прогон.
- **Аварийный:** временно внесена ошибка в шаг Check Unity
  Directories — бот прислал сообщение с именем упавшей задачи,
  автором и ссылкой на лог; задача notify при этом осталась зеленой.
  После проверки main.yml возвращен в рабочее состояние.

## Результат

Пайплайн полностью автоматизирован и информирует команду о любом
исходе: успех (ссылки на игру и прогон) или падение (задача, автор,
лог) — уведомления приходят в Telegram без открытия вкладки Actions.
